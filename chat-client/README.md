# Chat Client

Front-end web client for multi-model LLM chat via OpenRouter, built with React 19, TypeScript, and Vite.

For full project documentation, architectural decisions, model comparisons, and run instructions, please refer to the root [README.md](../README.md).

## Quick Start

```bash
npm install
npm run dev
```

Run test suite:
```bash
npm run test
npm run test:coverage
npm run e2e
```
